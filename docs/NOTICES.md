# 更新文字卡片

直接编辑 GitHub 仓库 main 分支的 NOTICE.md 并提交。每个 `## 标题` 对应圆环下方一个只读卡片，后面的文字是正文；换行保留，内容按纯文本显示。

```markdown
# 植被组通知

## 组内通知
在这里填写通知。

## 使用说明
在这里填写说明。

## 联系方式
在这里填写联系方式。
```

最多 6 个卡片，标题最多 80 字符、单卡正文最多 4000 字符，文档最多 32 KiB。删除一个章节会删除对应卡片；清空文档或删除文件会清空全部卡片。正文不要包含账号密钥。

打开、点击刷新及可见期间的十分钟刷新都会并行读取额度快照和文档，受同一十五秒查询间隔限制。不用触发额度工作流，也不用重新安装插件。文字读取失败时保留上次内容并显示“文字暂未同步”。

公开仓库允许匿名读取，私有仓库需要当前 GitHub 账号具有读取权限。仓库公开后，用量快照和文字文档也会公开。
